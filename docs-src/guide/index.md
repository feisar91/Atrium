# Guide

How-to and reference documentation for running Atrium beyond the initial install lives here. For installing Atrium itself, see the [install guide](/install).

- [Getting Started](/guide/getting-started) - connect a UniFi controller, sync sites, and build your first portal.
- [Configure UniFi](/guide/configure-unifi) - point guest WiFi at the portals you build in Atrium.
- [Set up Google Sign-In](/guide/google-sign-in) - let guests connect with one tap instead of filling in a form.

More guides are on the way.
